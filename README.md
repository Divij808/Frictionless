# Epoch

Epoch is the combined Flask productivity and Study Hub application.

It combines the original Frictionless productivity features with document processing, retrieval and local AI study tools from the test application.

The merged application uses separate HTML/Jinja templates for each major page and does not include the test application's JavaScript frontend.

See [Frictionless/MERGE_GUIDE.md](Frictionless/MERGE_GUIDE.md) for the merge and setup guide.
